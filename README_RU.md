# JARVIS для Redmi — стартовый Android-проект

Это небольшое Android-приложение на Kotlin: голосовой ввод на русском через системную службу распознавания Android, голосовой ответ через Text-to-Speech, чат с Groq и несколько локальных команд без ИИ.

## Что умеет

- Принимать голосовую команду после нажатия на 🎙️.
- Озвучивать ответы системным русским голосом телефона.
- Отвечать через Groq API (модель `llama-3.3-70b-versatile`).
- Без API работать с простыми командами: время, дата, открыть YouTube, Telegram, браузер и настройки.
- Шифровать сохранённый API-ключ с помощью Android Keystore.

## Важно

- Это не официальный клиент ChatGPT и не использует твой аккаунт ChatGPT. Для умных ответов нужен отдельный ключ Groq API.
- Приложение не гарантирует доступ к Groq из любой российской сети: это зависит от доступности сервера и конкретного провайдера. Локальные команды работают без Groq.
- Голосовое распознавание зависит от установленной в Android службы распознавания речи; для некоторых служб нужен интернет.
- Ключ создаётся в настройках приложения на телефоне и не добавляется в исходники или в APK.
- Разрешение микрофона используется только после нажатия на кнопку 🎙️; постоянного фонового прослушивания нет.

## Как получить APK через GitHub Actions

1. Создай новый пустой репозиторий GitHub с именем, например, `jarvis-redmi`.
2. Распакуй ZIP и загрузи **содержимое папки** в корень репозитория — в корне должны быть `settings.gradle.kts`, `build.gradle.kts`, папка `app` и папка `.github`.
3. Перейди в **Actions**. Если GitHub попросит — разреши запуск workflow.
4. Открой `Build JARVIS APK` и выбери **Run workflow** (или просто сделай commit/push — сборка стартует автоматически).
5. Когда сборка станет зелёной, открой её и скачай файл `JARVIS-Redmi-APK` в блоке **Artifacts**.
6. Распакуй ZIP с артефактом, открой `app-debug.apk` на Redmi и подтверди установку приложения из этого источника.

## Настройка после установки

1. Открой JARVIS и нажми `⚙ API`.
2. Создай ключ в `https://console.groq.com/keys` и вставь его в приложение.
3. Нажми 🎙️, разреши доступ к микрофону и скажи вопрос.
4. Если нет интернета/API, проверь локальные команды: `который час`, `скажи дату`, `открой YouTube`, `открой Telegram`, `открой настройки`.

## Сборка вручную

Нужны JDK 17, Android SDK 35 и Gradle 8.9. В корне проекта выполни:

```bash
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
